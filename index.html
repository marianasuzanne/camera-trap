  2. Crie um projeto → adicione um Web App
  3. Copie o firebaseConfig e cole abaixo
  4. Ative Authentication → Google
  5. Ative Firestore Database (modo teste)
  6. Em Authentication → Settings → Authorized domains, adicione seu domínio GitHub Pages
