🔥 Firebase — Login & Sincronização
Permite login e sincroniza dados entre celular e computador.
100% gratuito no plano Spark do Firebase.
  1. Acesse console.firebase.google.com
  2. Crie um projeto → adicione um Web App
  3. Copie o bloco firebaseConfig = {...} e cole abaixo (pode colar como o Firebase mostra)
  4. Ative Authentication → Google
  5. Ative Firestore Database (modo teste)
  6. Em Authentication → Settings → Authorized domains, adicione seu domínio GitHub Pages
